1) Этот триггер будет выполняться перед вставкой или обновлением данных в таблице "клиент". Он проверяет, что новый телефонный номер клиента не совпадает с телефонными номерами других клиентов в таблице. Если нарушение уникальности обнаружено, триггер генерирует исключение с сообщением об ошибке. Если проверка прошла успешно, триггер просто возвращает новые данные.


CREATE OR REPLACE FUNCTION check_unique_phone()
  RETURNS TRIGGER AS
$$
BEGIN
  IF EXISTS(SELECT 1 FROM public."клиент" WHERE phone = NEW.phone AND id <> NEW.id) THEN
    RAISE EXCEPTION 'Клиент с таким номером телефона уже существует';
  END IF;
  RETURN NEW;
END;
$$
LANGUAGE plpgsql;

CREATE TRIGGER unique_phone_trigger
  BEFORE INSERT OR UPDATE
  ON public."клиент"
  FOR EACH ROW
  EXECUTE FUNCTION check_unique_phone();

2) Этот триггер будет вызываться перед вставкой или обновлением строк в таблице "договор". Если новая строка содержит дату начала аренды, которая позже даты окончания аренды, то триггер вызовет исключение и изменения не будут сохранены в таблице.
CREATE OR REPLACE FUNCTION check_begin_rent_before_end_rent()
RETURNS TRIGGER AS $$
BEGIN
    IF NEW.begin_rent > NEW.end_rent THEN
        RAISE EXCEPTION 'Дата начала аренды должна быть не позже даты окончания аренды';
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER check_begin_rent_before_end_rent_trigger
    BEFORE INSERT OR UPDATE ON public."договор"
    FOR EACH ROW
    EXECUTE FUNCTION check_begin_rent_before_end_rent();

3) Этот триггер запускается перед обновлением каждой строки таблицы "точка", и если новое значение цены за день меньше 0, то он выбрасывает исключение и не дает обновить запись.

CREATE OR REPLACE FUNCTION check_price_day()
RETURNS TRIGGER AS $$
BEGIN
    IF NEW.price_day < 0 THEN
        RAISE EXCEPTION 'Цена за день не может быть меньше 0!';
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER check_price_day_trigger
BEFORE UPDATE ON public."точка"
FOR EACH ROW
EXECUTE FUNCTION check_price_day();


4) Этот триггер будет вызываться после каждой операции INSERT или UPDATE, которая изменяет столбец "payment" в таблице "оплата". Триггер вычисляет общую сумму платежей для данного договора и сравнивает ее с суммой, указанной в соответствующем договоре. Если общая сумма платежей превышает сумму аренды, триггер вызывает исключение.

CREATE OR REPLACE FUNCTION check_payment() RETURNS TRIGGER AS $$
DECLARE
  total_payment decimal;
  total_rent_price decimal;
BEGIN
  -- вычисляем общую сумму платежей для данного договора
  SELECT SUM(payment) INTO total_payment
  FROM public."оплата"
  WHERE id_договор = NEW.id_договор;

  -- получаем сумму из договора
  SELECT  (SUM(p.price_day * (EXTRACT(day from NEW.end_rent::timestamp - NEW.begin_rent::timestamp ) + 1))) - COALESCE(o.total_payment, 0)
INTO total_rent_price
  FROM public."договор" d
  INNER JOIN public."точка" p ON d.id_точка = p.id
  WHERE d.id = NEW.id_договор;

  IF total_payment > total_rent_price THEN
    RAISE EXCEPTION 'Сумма оплаты превышает стоимость аренды для данного договора';
  END IF;

  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER check_payment_trigger
AFTER INSERT OR UPDATE OF payment ON public."оплата"
FOR EACH ROW
EXECUTE FUNCTION check_payment();


5) Этот триггер использует функцию plpgsql increment_id(), которая выбирает максимальное значение поля "id" из таблицы "клиент" и увеличивает его на 1. Затем, триггер increment_id_trigger вызывает эту функцию перед каждой вставкой новой записи в таблицу "клиент", присваивая значение "id" для новой записи.

CREATE OR REPLACE FUNCTION increment_id()
RETURNS TRIGGER AS $$
BEGIN
  NEW.id = (SELECT COALESCE(MAX(id), 0) + 1 FROM "клиент");
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER increment_id_trigger
BEFORE INSERT ON public."клиент"
FOR EACH ROW
EXECUTE FUNCTION increment_id();
