ЛАБОРАТОРНАЯ РАБОТА №2
Операторы реляционной албебры

Цель: научиться использовать операторы реляционной алгебры (объединение, пересечение, разность, декартово произведение, выборка, проекция, соединение) в таблицы БД на основе оператора SELECT

Лабораторная работа № 2 выполняется на основе модели базы данных, полученной в лабораторной работе № 1.

Задачи:
1. Подготовить модель "сущность-связь" по заднной предметной области в программе pgModeler (пример в файле insurance_DB.dbm)
2. В программе pgModeler установить соединение в сервером PostgreSQL
3. Выполнить экспорт модели из pgModeler в PostgreSQL.
4. Открать pgAdmin, убедиться, что новая БД появилась и присутствуюь все необходимые таблицы.
5. Заполнить ВСЕ таблицы картежами таким образом, чтобы было проиллюстрированы основные правила предметной области, связанные с кратность отношений (например, в одном филиале может работать несколько сотрудников, договор заключается на несколько видов страхования, один вид страхования может участвовать в разных договорах и т.д.). Рекомендуется не менее 3-4 кортежей на таблицу.
Для удобства заполнения можно сформировать скрипты на основе оператора вставки данных INSERT (пример в файле insert.sql).
6. Отработать использование SELECT для выполнения основных операций реляционной алгебры. Примеры придумать самостоятельно на основе образца в файле relation_algera.sql.
Обзательно должны быть селекты на следующие задачи:
	- образить все данные из произвольной таблицы,
	- выполнить проекцию данных на произвольной таблице (в том числе с созданием дополнительных вычисляемых столбцов),
	- выполнить фильтрацию данных с использованием выражений LIKE, IN, NOT NULL, BETWEEN, AND, OR и т.д
	- выполнить соединение нескольких таблиц (привести примеры на внутреннее INNER JOIN и внешние LEFT|RIGHT JOIN соединения, проанализировать результаты, установить, в чем из разница)
	- выполнить объединение|пересечение|разность данных (для выполнения этих операия сначала можно реализовать разные фильтры на одной таблице, а потом выполнить объединение|пересечение|разность на плученных результатах)
Все операторы SELECT должны быть протестированы на отсутствие ошибок и получение верного результата.


Результат:
1. Диаграмма "сущность-связь" в файле *.dbm (или растр с изображением диаграммы).
2. Файл с интрукциями INSERT для вставки данных в таблицы (пример insert.sql)
3. Файл с оператрами SELECT с пояснениями, что делает каждый SELECT (пример relation_algera.sql)
